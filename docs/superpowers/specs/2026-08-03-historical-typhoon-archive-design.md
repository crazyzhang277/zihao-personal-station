# 历史台风档案设计

## 目标

在现有台风页中增加“实时台风 / 历史台风”双模式。历史模式提供 1980 年至今的西北太平洋真实最佳路径，可按年份、中文名、英文名或编号查询，并一次查看一条台风。

## 数据与部署

- 数据源为 NOAA/NCEI IBTrACS v4r01 的西太平洋 CSV。
- 构建前脚本把 CSV 转换成一个轻量索引和按年份拆分的静态 JSON。
- 生成数据随 `dist` 发布，浏览器不直接依赖 NOAA、后端、数据库、代理或环境变量。
- 资源使用相对 URL，同时兼容 GitHub Pages 子路径和 Cloudflare Pages 根路径。
- 普通 `npm run build` 只使用仓库内已有数据。NOAA 不可用不会阻断网站部署。
- GitHub Actions 每月更新一次数据；验证数量、体积、测试和构建后直接提交到 `main`，仅授予 `contents: write`。

## 数据模型

索引记录包含 IBTrACS SID、年份、编号、英文名、可选中文名、起止时间、最大风速、最低气压、最强等级和轨迹点数。分年文件保存每条台风的时间序列点：时间、经纬度、风速、气压和自然类型。

中文名称通过仓库内人工维护映射提供。没有可靠中文名时只显示英文名和编号，不机器翻译。缺失的风速或气压保持为空，不补零。

## 页面交互

- 地图工具栏增加双档模式切换，默认保持实时模式。
- 进入历史模式时停止自动刷新并清除实时图层；离开时恢复实时快照和自动刷新。
- 历史工具栏包含年份选择、名称或编号搜索和结果计数。
- 右侧面板显示过滤结果；点击一项只加载并绘制该台风。
- 历史路径按强度分段着色。地图只显示稀疏关键节点、起点和终点，避免密集圆点。
- 详情显示名称、编号、起止时间、持续时间、最大风速、最低气压和最强等级。
- 历史模式不绘制预报线和风圈，并明确标注“历史最佳路径并非实时预报”。

## 错误与空状态

- 索引加载失败时提供重试，不影响实时模式。
- 年份文件加载失败时保留筛选条件并提供重试。
- 无结果时提示尝试中文名、英文名、编号或其他年份。
- 未选择台风时显示引导状态，不绘制默认杂乱路径。
