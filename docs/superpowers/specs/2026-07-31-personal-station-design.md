# 张梓皓个人观测站 设计规格

> 状态：已确认（2026-07-31）
> 定位：一个集实时观测、工具实验与个人展示于一体的模块化控制台网站。

## 1. 站点定位

网站以「个人观测站」为核心概念：首页像一份持续出版的观测杂志，二级菜单承载不同工具与数据页面。它同时承担个人展示与功能集成的角色，后续可以继续追加模块。

## 2. 视觉方向

- **纸感编辑控制台**：暖纸色背景、墨色文字、朱红点缀、细线分割。
- 主色：纸面 `#F4F0E8`，墨色 `#17140F`，次级灰 `#6D675B`，朱红 `#A63C2B`。
- 展示字体：`Georgia / Times New Roman / Songti SC` 衬线字体；正文：`Avenir Next / Segoe UI / PingFang SC / Microsoft YaHei`；数据与标签：等宽字体。
- 记忆点：每页使用期刊式报头「张梓皓 / ZHANG ZIHAO / PERSONAL STATION / VOL. 01 — 2026」、红色「梓」字印章、页眉期号标签与发丝线。
- 动效克制：页面载入轻微显现、卡片悬停微反馈；尊重 `prefers-reduced-motion`。

## 3. 信息架构

- 顶级导航：总览、观测、实验、关于。
- 二级菜单：观测下包含台风雷达、天气站、网络探针；桌面端为下拉菜单，移动端为可折叠菜单。
- 页面：`总览`、`台风雷达`、`天气站`、`网络探针`、`实验舱`、`关于`。

## 4. 页面规格

### 总览
- 编辑风 hero：姓名、站点名、一句话定位。
- 实时摘要卡片：台风路径（演示数据）、天气（Open-Meteo）、网络状态（浏览器连接信息）。
- 模块入口网格与「关于」摘要。

### 台风雷达
- 西太平洋 SVG/Canvas 地图，演示台风路径。
- 状态面板：台风名、强度、位置、移速、中心气压。
- 时间步进控件与图例；数据存放在类型化模块中，预留替换实时 API 的接口。

### 天气站
- Open-Meteo 获取当前天气与 7 日预报。
- 默认上海，提供上海 / 北京 / 广州切换。
- 请求失败时展示演示数据并明确标注降级状态。

### 网络探针
- 展示浏览器连接信息（`effectiveType`、`downlink`、`rtt`）。
- 「开始探测」按钮测量多个 CORS 友好端点的 fetch 延迟，绘制延迟历史。
- 浏览器不支持时降级说明。

### 实验舱
- 至少一个可用工具：台风强度换算。
- 其他实验以「规划中」卡片呈现，保持诚实状态。

### 关于
- 可编辑个人简介、技术兴趣、联系方式占位；文案统一放在类型化内容模块中。

## 5. 数据与错误策略

- 天气使用无密钥 Open-Meteo；网络探测使用浏览器 API 与 CORS 友好端点；台风先使用演示数据，接口层保持类型化以便替换。
- 所有外部请求失败都应优雅降级，不允许白屏。
- 页面文案保持中文、具体、无占位 Lorem ipsum。

## 6. 技术架构

- Vite + TypeScript 多页应用，不引入 React 等框架。
- 页面：6 个 HTML 入口；共享导航、样式与数据模块。
- 目录边界：`src/styles`、`src/data`、`src/lib` 等按职责拆分。
- 脚本：`dev`、`build`、`preview`；构建必须通过且无 TS 错误。

## 7. 验收标准

- `npm run build` 成功。
- 桌面与移动端可用，键盘可操作，二级菜单可展开。
- 六个页面均可从导航到达。
- 台风、天气、网络、实验模块均有明确内容，不出现空白占位。
